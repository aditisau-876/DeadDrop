# DeadDrop
Publicly Verifiable, Policy-Composable Emergency Recovery Protocol.

Starter repository based on the uploaded DeadDrop documentation. It contains:
- frontend/: React + TypeScript + Vite dashboard
- backend/: FastAPI coordination API
- contracts/: Solidity/Foundry MVP state machine
- docs/: architecture, implementation plan, security notes, API and data model

Important: this is an implementation scaffold, not a claim of production-ready cryptography.
We will build the protocol incrementally, starting with a tested 3-of-5 flow.
